# 라우팅 정답 기준

영상 요청 한 문장에 "만드는 도구(또는 하는 도구)" 하나를 정답으로 붙인다. 정답 id 는 아래 11개 중 하나.

| id | 언제 |
|---|---|
| huashu-motion | 앱·기능 런칭/홍보 영상(릴스·쇼츠 포함), 음악 박자 맞춘 모션그래픽, 숫자·CSV 데이터 영상, 내가 찍은 토킹헤드 영상에 자막·이름표·그래픽 얹기, **한국어** 내레이션 설명 영상(녹음/유나 목소리) |
| take-one | 이야기형 광고, 브랜드 필름, 뮤직비디오, "최고 완성도" 연출 중심 영상 |
| argo | 내 실제 앱(웹)을 자동으로 눌러 가며 녹화한 데모·튜토리얼, 기존 Playwright/E2E 테스트를 데모 영상으로 |
| explainroo | **영어** 주제 설명 영상(대본·목소리·그림·자막·썸네일 자동), 유튜브 설명 영상 |
| rossark | 앱 안에 들어갈 캐릭터·마스코트·아이콘 애니메이션(대기 동작, 반응 동작, 루프) |
| reanimate | 남의 사이트·앱·영상의 애니메이션을 내 코드로 복제 ("저 사이트처럼 움직이게") |
| earshot | 이미 있는 영상에 효과음 넣기, 소리가 화면 컷과 맞는지, 음량(LUFS) 검사 |
| real-sound | 실제 녹음 음원(Freesound 등)으로 사운드트랙·배경음악 전체를 깔기 |
| watch | 남의 영상(유튜브·릴스 링크) 분석: 컷 길이, 첫 3초 구성, 훅 |
| kling | 사람·풍경 같은 실사 장면을 AI로 생성 (돈 드는 생성) |
| video-director | 이미 만든 영상 완성본을 기준표로 검사(글자 크기, 첫 프레임, 번쩍임, 안전 영역 등) |
